# UK English Requirement

When invoking this skill for Dan's content, always use UK English spellings:

- organise (not organize)
- optimise (not optimize)
- analyse (not analyze)
- behaviour (not behavior)
- colour (not color)
- centre (not center)
- defence (not defense)
- licence (verb: to licence; not license)
- programme (not program, except computer programs)

This applies to all humanized output produced by this skill.
